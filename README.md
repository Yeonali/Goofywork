# Goofywork — AI Student Study Planner

This repo contains a minimal Next.js starter for an AI-powered student study planner inspired by Notion, Google Calendar, and habit trackers.

## What is included
- Dashboard UI layout with scheduler, notes vault, exams, weekly planner, to-dos, habits, and AI assistant.
- Backend API route stubs for AI prompts, schedule generation, uploads, and OCR.
- Data model references for Firestore/MongoDB.
- Scheduling and prioritization helpers.

## Getting started
```bash
npm install
npm run dev
```
